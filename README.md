# EchoBox

Offline music player for Android, built with Kotlin and Jetpack Compose.

## Build

GitHub Actions builds the debug APK on every push to `main` (or run it manually from the Actions tab).
Download `EchoBox-debug-APK` from the finished run's Artifacts and install it on your phone.

## Roadmap

Add one feature at a time, commit, let Actions build it, test the APK, then continue.

1. Starter project and GitHub Actions workflow
2. Bottom navigation and dark theme
3. Music scanning (MediaStore)
4. Library screen
5. Playback engine
6. Background playback
7. Queue management
8. Favorites
9. Playlists
10. Listening history
11. Statistics screen
12. Final testing
